> [!NOTE]
> "infer" = inference - thuật ngữ AI, nghĩa là "chạy model để dự đoán". Khi model đã train xong, bạn đưa ảnh mới vào để model suy luận ra kết quả = running inference. Đặt tên infer/ cho thư mục Python service vì nó chỉ làm mỗi việc đó (để tránh việc bạn không hiểu tên thư mục hoặc mục đích của thư mục này)
